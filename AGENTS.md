# Instructions for work in this repository

Before translating, editing a translation, or adding chapters, read `TRANSLATION.md` and `GLOSSARY.md` in full. Apply them alongside the author's current instructions and Russian source.

- Keep Russian source text verbatim and translate the complete chapter into English.
- Consult published chapters for continuity. Keep names, powers, institutions, and technical distinctions consistent with the glossary.
- Update the glossary whenever new recurring terminology appears. Record unresolved choices and terminology revisions; do not silently invent or change lore.
- When an established English term changes, review earlier occurrences and update affected chapters consistently, following the revision workflow in `TRANSLATION.md`.
- Add both language versions to `book.json`; run `python3 build.py` and check contents, chapter navigation, language links, and completeness before publishing.
- Keep translation documentation in the repository, outside `docs/`. Do not add it to the reading interface unless requested.

The full translation workflow and authority rules are in `TRANSLATION.md`.
